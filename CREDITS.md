## Original Creator & Visionary
**AutoExpert** was created and open-sourced by **Dustin Miller** ([@spdustin](https://github.com/spdustin)):
- GitHub: [https://github.com/spdustin](https://github.com/spdustin)
- Original Upstream Repository: [spdustin/AutoExpert-AutoExpert](https://github.com/spdustin/AutoExpert-AutoExpert)
- Substack: [https://spdustin.substack.com](https://spdustin.substack.com)
- Reddit: [u/spdustin](https://www.reddit.com/u/spdustin)

Dustin Miller pioneered the foundational breakthroughs that define AutoExpert:
1. **Dynamic Expert Persona Induction**: Bypassing generic assistant weights by priming the model's emergent attention mechanisms toward deep, domain-specific authority roles.
2. **Attention Steering Preambles**: Guiding token prediction at the start of every completion with formal keywords, role identification, and chain-of-thought methodologies.
3. **Verbosity Dialing (V=0 to V=5)**: Giving users fine-grained control over information density and signal-to-noise ratio.
4. **Slash Command Taxonomy**: Standardizing intuitive commands (`/help`, `/review`, `/q`, `/more`, `/links`, `/redo`, `/alt`, `/stash`, `/recall`) directly within conversational models.
5. **autodev.py**: Creating the Advanced Data Analysis / Code Interpreter Python environment manager, integrating Universal Ctags, sandbox inspection, and state preservation.

## Architectural Evolution & Universal Extensions
Over 4+ years of real-world use, **Sean Tyler** ([@seanbuilds](https://github.com/seanbuilds)) extended and adapted Dustin Miller's framework to modern frontier AI architectures:
- **Gemini Native Port & REV1**: Restructured the framework for ultra-large context windows (1M–2M tokens), Gemini Gems, and evidence-first Google Search grounding.
- **Universal Multi-Model Edition**: Generalized the prompt architecture across OpenAI GPT-4o, Anthropic Claude 3.5/3.7, and Google Gemini 2.0 with the **Strategy & Context Table**.
- **No-Elision Mandate & Source Tree Epilogues**: Formalized rigorous pair-programming standards where placeholders are forbidden, and turn-by-turn state is tracked via standardized filesystem emoji trees.
- **Agentic Skill Suite**: Integrated AutoExpert into autonomous coding agent ecosystems (Google Antigravity, Open Interpreter, Claude Code).
