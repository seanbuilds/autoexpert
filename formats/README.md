# AutoExpert — Distribution Formats

Ready-to-use copies of the core AutoExpert prompts, adapted for specific platforms and agent frameworks.

## Directory Structure

```text
formats/
├── agent_skills/
│   ├── antigravity/       # Google Antigravity agent skill
│   ├── claude_code/       # Claude Code CLI agent skill
│   └── open_interpreter/  # Open Interpreter agent skill
└── system_prompts/
    ├── standard/          # Copy of core/standard/ — general use
    └── developer/         # Copy of core/developer/ — programming
```

## Source of Truth

The canonical prompts live in `core/`. Files in this directory are portable copies for convenient distribution.
